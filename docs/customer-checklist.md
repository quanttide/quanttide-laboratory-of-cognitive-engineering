# 客户视角自查清单

每次输出交付物前，用这 5 个标准做一次自查。

## 五问

| # | 问题 | 客户的潜台词 | 检查要点 |
|---|------|-------------|---------|
| 1 | 可信吗？ | 凭什么信你说的？数据来源是什么？ | 报告本体中直接展示数据来源，不依赖附件 |
| 2 | 跟我有关吗？ | 你说的是我的问题吗？还是通用模板？ | usage 是否 3 秒内让客户判断"这是我的问题" |
| 3 | 风险在哪？ | 哪些是确定的？哪些还要再看看？ | 用 ✅⚠️❓ 直接标注，不藏在扣分理由里 |
| 4 | 能直接用吗？ | 看完我能给我团队发指令吗？ | mappings 是否具体到"下周一开始做什么" |
| 5 | 值吗？ | 比别的咨询公司多给了什么？ | 方法论附加值是否包装为客户可感知的语言 |

## 自查流程

1. 写完报告后逐条过一遍
2. 对每个问题，如果答案是"客户需要翻其他文件才能回答" → 扣分
3. 全部 5 个问题都能在报告本体中回答 → 通过

## 与内部质量维度的关系

| 内部门槛（quality-framework） | 客户感知（customer-checklist） |
|----|----|
| B-2 外部有效性 | 可信吗？——数据来源在报告本体内可见 |
| B-3 任务适用性 | 跟我有关吗？+ 能直接用吗？ |
| A-2 灵活性 | 风险在哪？——保留类/需验证类直接标注 |
| B-4 可沟通性 | 综合——所有 5 问 |
