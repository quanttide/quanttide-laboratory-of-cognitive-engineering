# 图式：技术升级

**实体**: 升级阶段, 隔离模式, 治理机制, 节奏信号

**因果链**:
- 未完成范式认知 → 用单租户思维做多租户改造
- 连续3周无可见产出 → 团队动力归零
- 第三个租户提出同类需求 → 进入下一级隔离
- POC验证可行 → 全面推广
- 外部评审介入 → 打破架构思维定势
- 标准化在实践中生长 → 系统自我维护

**边界**:
- 适用于创始人型组织
- 排除外包团队/无决策权场景
- 需要"范式升级"共识

**映射**:
- 防旧思维做新架构 → M0认知对齐+POC
- 避免过度设计 → 逻辑隔离起步，第三租户再抽象
- 维持动力 → 每阶段≤3周，阶段间设缓冲
- 决策可追溯 → ADR记录
- 规范不阻碍实践 → 升级中自然沉淀

**偏见**:
- 加字段≠范式重构（最大误区）
- 一步到位≠渐进可控（反脆弱）
- 先定标准≠实践生长（元智能）
- 纯技术问题≠认知节奏瓶颈（元意图）
- 招人≠体系化（反例）
- POC成功≠架构可行（独立评估）
