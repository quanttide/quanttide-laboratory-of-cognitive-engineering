# 项目三：图谱推理价值验证

**核心问题**：图谱（intent.yaml + intent-relation.yaml）能否发现文本本身看不出的隐含关联？

## 验证方法

```
测试输入 → 同时走两条路径对比

路径 A（无图谱）：仅凭文本内容做直觉分析
路径 B（有图谱）：匹配 Intent → 沿图边走 → 推理隐含关联

→ 对比：B 比 A 多了什么有价值的信息？
```

## 任务

### 3.1 准备测试输入

从 `assets/raw/` 之外准备 3 段测试文本，每段只谈一个表面话题但隐含深层关联。

**方法**：
1. 选取一段仅谈研发疲惫的文本（表面话题：心理状态）
2. 选取一段仅谈招人难的文字（表面话题：团队建设）
3. 选取一段仅谈代码质量的文字（表面话题：技术）

**输出**：`inputs/test-cases.md`，三段原始文本

### 3.2 无图谱对照分析

仅凭文本内容，不做图谱参考，对 3 段输入做直觉分析。

**方法**：
1. 逐段阅读，凭直觉判断作者可能关联的问题
2. 不引用任何 Intent/关系数据
3. 输出分析结论

**输出**：`outputs/baseline.md`，每段文本的直觉分析

### 3.3 图谱推理分析

以 `intent.yaml` + `intent-relation.yaml` 为上下文，对 3 段输入做图谱推理。

**方法**：
1. 匹配输入到 Intent 簇
2. 沿图谱边行走，提取二阶关联（关联的关联）
3. 标注冲突路径
4. 生成推理链

**输出**：`outputs/graph-inference.md`，每段文本的推理过程 + 推理链 JSON

### 3.4 对比评估

对比 3.2 和 3.3 的结果，评估图谱的增量价值。

**评估维度**：
1. **隐含关联发现** — B 发现了 A 没发现的关联吗？
2. **反直觉度** — 发现的关联是否反直觉但合理（非废话）
3. **可追溯性** — 推理结果是否能追溯到图谱中的具体边

**输出**：`outputs/comparison.md`，每组的对比表和结论
