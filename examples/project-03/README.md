# 项目三：方案A — 无模型基准线

基于关键词匹配的纯文本意图识别，作为方案B 的**基线对照**。

## 定位

不要模型也能做到什么程度？方案A 是方案B 的"无模型对照组"，两者的差距就是图谱推理的增量价值。

方案A 与方案B 共享完全相同的**关键词表和匹配逻辑**，唯一差异是有无知识图谱。

**输入**：`../../../assets/refined/intent.yaml`（节点名 + per_week 表述）

## 任务

### 3.1 构建关键词表

从 `intent.yaml` 提取 10 个 Intent 簇的 `name` 和 `per_week` 表述，去停用词后作为每簇的关键词表。

**方法**：
1. 解析 YAML，提取 `id`、`name`、`per_week` 中的 intent 表述
2. 分词 + 去停用词（"的、了、是、在、有、我、这"等），去重
3. 序列化为 JSON

### 3.2 匹配算法

**算法**：
1. 对输入文本按相同规则分词、去停用词
2. 对每个簇，计算匹配度：`|intersection(文本词, 簇关键词)| / |簇关键词|`
3. 匹配度 > 阈值（待定，通过 W19-W23 数据调优确定）则判定为该簇

**输出**：stdout JSON

```json
{
  "matched": [
    {"id": 1, "name": "研发方法论", "score": 0.20, "evidence": ["研发", "效率"]}
  ]
}
```

**源码**：`src/main.rs`
