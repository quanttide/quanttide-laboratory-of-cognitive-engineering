## 心智模型活跃度

### 商务拓展

适用于产品经理和创业者评估新想法时参考

| 维度 | 内容 |
|------|------|
| 因果信念 | IF 新想法通过低门槛验证 → 可行后结构化复制；IF 验证失败 → 低成本放弃 |
| 常见偏差 | 所有想法都值得先投入（事实：低门槛验证可快速筛选无效想法）；验证成功就等于有商业价值（事实：验证成功只是技术可行，商业价值需要独立评估） |
| 适用边界 | 适用于商业和研发探索；排除高投入长期项目；验证周期不超过两周 |

### 组织管理

适用于中小型组织转型阶段参考

| 维度 | 内容 |
|------|------|
| 因果信念 | IF 依赖人治 → 组织温度高但脆弱；IF 建立制度且保留弹性 → 韧性增强且温度不骤降 |
| 常见偏差 | 招人补位即可解决（事实：制度化才是根本但需保留温度） |
| 适用边界 | 适用于中小型组织（5-50人）；需要创始人对组织温度有敏感性 |

### 身心健康

适用于高压探索阶段的操作者自我觉察

| 维度 | 内容 |
|------|------|
| 因果信念 | IF 元意图得到维护 → 其他意图可持续运作；IF 元意图被忽视 → 高压探索产生无意义感 |
| 常见偏差 | 高压探索必须牺牲健康（事实：元意图保障可维持长期产出） |
| 适用边界 | 适用于高压探索阶段；需要操作者对自身状态有觉察能力 |

## 跨域认知模式

### 结构化收敛 vs 快速试错

**涉及情境**：认知工程、创新管理

**表现**：意图工程要求"想清楚再做"（结构化消耗认知），POC 范式要求"做了再想"（快速试错节省认知）。W23 同时确立这两个方法论，循环两端已就位，但交替节奏尚未建立。

**心智模型支撑**：意图工程框架、低门槛验证

### 心理预算约束

**涉及情境**：身心健康、创新管理、组织管理

**表现**：三个独立情境交汇于"有限的心理能量如何在高压探索中持续分配"。POC 质量与心理压力构成负反馈循环。

**心智模型支撑**：元意图保障

## 认知偏差识别

- **意图工程万能论**（情境：认知工程）
  - 信念：一切结构化生成过程都可统一为意图工程
  - 事实：核心假设尚未被大规模验证
  - 状态：待验证（需在至少一个新领域验证后固化为可信模型）

- **标准化即终点**（情境：元）
  - 信念：标准化是独立运动，需要主动推进
  - 事实：标准化是元智能成熟度的自然产出
  - 状态：已修正（合并回元职能的决策已验证此偏差）

- **制度化决定一切**（情境：组织管理）
  - 信念：建立制度就能解决问题
  - 事实：制度化可能丧失人治温度
  - 状态：觉察中（06-06 已识别"微妙的中间态"但解法未定）
