# 模型定义

## 念头（Notion）

**定义**：日志中的原始信息单元，是未经加工的思考记录。

**来源**：默认日志（如 `assets/founder-journal/2026-06-01.md`）中的自然段落。

**特征**：
- 原始性：未经分类、未识别意图、未建立关系的原始素材
- 时间锚定：每条念头具有明确的日期标记
- 话题模糊：一条念头可能涉及多个话题，需后续以意图为边界进行区分

**在实验中的位置**：
念头 → 话题（Topic）→ 意图识别 → 意图关系 → 意图结构化输出
（task 1.1 的输入即为念头集合，输出是按话题归类的分组）

---

## 话题（Topic）

**定义**：以意图为边界聚合的念头集合，是意图识别的前置分组。

**来源**：task 1.1 的输出，由念头按意图边界归类形成。

**特征**：
- 意图边界性：同一话题内的念头共享或指向同一意图
- 跨日性：一个话题可能跨越多天日志出现
- 可嵌套性：一个话题可包含子话题，但以保持意图纯度为准

**命名规范**：用简洁的名词性短语，如"团队机制与文化转型"

**在实验中的位置**：
念头 → 话题（Topic）→ 意图识别 → 意图关系 → 意图结构化输出
（task 1.2 的输入即为话题分组，输出是从每个话题中提取核心意图）

---

## 意图（Intention）

**定义**：驱动念头产生和话题聚合的核心动机，是想法的最小结构化单元。

**来源**：task 1.2 的输出，从话题的念头集合中提炼而来。

**表述规范**：以"为了……"或"想要……"句式，明确指向行动或期望状态。

**特征**：
- 动机性：意图是念头背后的"为什么"，而非念头本身
- 关系性：意图之间可形成支持、冲突、包含、演进等关系
- 层级性：一个意图可包含子意图，形成意图树
- 跨话题性：一个意图可能出现在多个话题中

**清晰度分级**：
- 清晰：可从念头中直接提炼，证据充分
- 较清晰：可推断，但存在多个可能解读
- 模糊：线索不足，需更多上下文才能确认

**在实验中的位置**：
念头 → 话题（Topic）→ 意图（Intention）→ 意图关系 → 意图结构化输出
（task 1.3 的输入即为意图列表，输出是意图之间的关系图）
