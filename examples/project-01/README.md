# 项目一：默认日志意图建模

基于最近一周（2026-06-01 至 2026-06-07）的默认日志，建立意图及意图关系的领域模型。

## 任务

### 1.1 话题分类

基于最近一周（2026-06-01 至 2026-06-07）的默认日志，按话题进行归类整理。

**输入**：`assets/journal/default/2026-06-01.md` ~ `2026-06-07.md`（7 篇）

**方法**：
1. 逐日阅读每篇日志，以自然段落为单位提取话题片段
2. 以"意图"为边界区分话题——同一意图导向的内容归为一个话题
3. 跨日出现的相同话题合并归类
4. 暂难归类的内容归入"其他"待后续澄清

**输出**：`outputs/task-1.1-topic-classification.md`，每个话题按以下格式交付：

```markdown
## 话题：{话题名称}

**涉及日期**：06-01, 06-03, ...

**关键段落**：
- `2026-06-01.md`：> {原文片段}
- `2026-06-03.md`：> {原文片段}

**备注**：{跨日演变、模糊点等}
```

**预期话题示例**（待验证）：
- 艺术量化与认知工程思路
- 意图识别方法论
- 叙事工程代码整合
- 日志格式与记录方式

### 其余任务

| 编号 | 任务名称 | 描述 |

| 1.2 | 意图识别 | 在每个话题中识别核心意图，提取关键表述 |
