# 项目五：方案A vs 方案B 对比测评

独立运行方案A 和方案B，以 `intent-analysis-report.md` 为基准，系统评估两者的召回率、误报率和推理路径质量。

## 核心问题

使用知识图谱的推理（方案B）比纯文本关键词匹配（方案A）能否发现更多有价值的隐含关联？增量价值有多大？

## 验证框架

```
5 段测试文本 ──→ 分别输入方案A 和方案B ──→ 对比结果 vs 基准
```

## 任务

### 5.1 测试集

从 `../../assets/raw/` 中选取 5 段原始日志文本，覆盖不同周次和话题：

| 编号 | 来源 | 表面话题 | 基准中涉及的 Intent 簇 |
|:----:|------|---------|----------------------|
| T1 | W19 某段 | 研发效率 | 簇1 研发方法论 + 簇3 认知工程 |
| T2 | W20 某段 | 团队管理 | 簇8 团队建设 + 簇5 商业模式 |
| T3 | W21 某段 | 认知负荷 | 簇2 心理可持续性 + 簇3 认知工程 |
| T4 | W22 某段 | 商业验证 | 簇5 商业模式 |
| T5 | W23 某段 | 工具链 | 簇1 研发方法论 + 簇6 平台架构 |

**输出**：`data/test-set.json`

```json
[
  {"id": "T1", "week": "2026-W19", "text": "...", "baseline_clusters": [1, 3]},
  {"id": "T2", "week": "2026-W20", "text": "...", "baseline_clusters": [8, 5]},
  ...
]
```

### 5.2 执行测试

**方法**：
1. 对每条测试文本，分别调用方案A 和方案B 的 binary
2. 收集输出的 JSON 结果

```bash
# 方案A
cat data/test-set.json | jq -c '.[].text' | while read text; do
  echo "$text" | cargo run --bin approach_a -p project-03
done

# 方案B
cat data/test-set.json | jq -c '.[].text' | while read text; do
  echo "$text" | cargo run --bin approach_b -p project-04
done
```

**输出**：`outputs/raw-results-a.json` + `outputs/raw-results-b.json`

### 5.3 对比分析

以 `../../assets/analysis/intent-analysis-report.md` 为 ground truth，逐项对比。

| 对比维度 | 基准（人工分析） | 方案A（文本匹配） | 方案B（图谱推理） |
|---------|----------------|-----------------|-----------------|
| 匹配到的 Intent 簇 | 报告中涉及的簇 | 关键词匹配结果 | 关键词匹配结果 |
| 推理出的关联 | 报告中标注的关系 | 无（只能匹配） | 邻居 + 2跳路径 |
| 检测到的冲突 | 报告中标注的冲突 | 无 | 冲突边 + 间接冲突 |
| 可追溯性 | 引用原文段落 | 关键词证据 | 引用图谱边+logic |

### 5.4 评估指标

**量化指标**（自动计算）：

| 指标 | 定义 |
|:----|------|
| 正检率 | 方案匹配到的 Intent 数 ÷ 基准中涉及的 Intent 总数 |
| 误报率 | 方案匹配到但基准中不存在的 Intent 数 ÷ 方案匹配总数 |
| 额外发现数 | 方案B 推理出的、基准中也认可的关联边数量 |

**质量指标**（人工评审）：

对方案B 输出的每条推理路径，逐条打标：

| 等级 | 标签 | 说明 |
|:----:|------|------|
| 3 | 强洞察 | 路径揭示了文本表面未提及、但基准认可的深层关联 |
| 2 | 合理 | 路径在逻辑上成立，但属于常识级推理 |
| 1 | 弱相关 | 路径技术上正确（边存在），但实际意义不大 |
| 0 | 误推 | 路径基于图谱边，但在该文本上下文中不成立 |

### 5.5 结论报告

**输出**：`outputs/comparison.md`

- 5 组测试的三列对比表（基准 / 方案A / 方案B）
- 正检率和误报率计算（按组 + 汇总）
- 推理路径质量评审表（每条路径的等级和评审说明）
- 图谱推理的增量价值结论
