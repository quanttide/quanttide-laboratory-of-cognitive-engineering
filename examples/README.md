# 示例项目

本目录包含认知工程的各类示例项目和实验资产。

## 实验要求（2026-06-08）

### 核心目标
验证**意图**能否作为叙事工程的灵魂——在思考和想法之间产生一致性，类似母题在叙事中的关键作用。

### 实验方向
- **实验数据**：不再让 AI 随机寻找，而是预先在实验室中准备好实验资产
- **数据入口**：以最近一周的默认日志作为切入点（AI 与作者既陌生又熟悉，适合验证 AI 能否从想法中建立结构）
- **建模重点**：不仅识别意图，更要识别意图之间的结构（关系图），最终得到一个**意图及意图关系的领域模型**

### 实验组织
- 分级结构：**项目**和**任务**两级（替代之前的实验室/实验，实验室调整为 program 级别）
- 一个实验室（program）应产出单一结果
- 项目和任务需前置组织，不能随意创建

### 方法论
1. 默认日志信息量大，先按**话题**分类
2. 以**意图为边界**区分话题
3. 识别话题中的意图
4. 意图逐步包裹为完整的想法
5. 重构周期在项目内统一管理
