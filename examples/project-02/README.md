# 项目二：思维演变长期分析

在一个月时间尺度（05-06 ~ 06-07）上追踪话题和意图的演变，识别持续存在的固有张力。

**核心问题**：
- 05-06~05-25 期间有哪些核心话题和意图？
- 与 06-01~06-07 的 13 个 Intent 相比，哪些持续、哪些消失、哪些新出现？
- 消失和出现之间是否有因果关系？

## 任务

### 2.1 老日志话题标注

**输入**：`../../assets/raw/2026-05-06.md` ~ `2026-05-25.md`（20 篇）+ `../../assets/refined/topics.md`（Project 1 的 9 个话题作为参考框架）

**方法**：
1. 快速浏览 20 篇老日志，以 Project 1 的 9 个话题为参考框架标注段落归属
2. 允许出现新话题——老数据可能涉及 Project 1 未覆盖的领域
3. 记录跨越 05-06~05-25 和 06-01~06-07 两个时间段的话题迁移

**输出**：`outputs/topic-coverage.md`
- 老日志中出现的话题及出现频率
- 在 Project 1 中但未在老日志中出现的话题
- 老日志中有但 Project 1 中没有的**新话题**

### 2.2 意图对比与演变分析

**输入**：2.1 的话题标注结果 + `../../assets/refined/intents.md`（13 个 Intent）

**方法**：
1. 从 2.1 识别出的老日志话题中提炼核心 Intent
2. 与 Project 1 的 13 个 Intent 逐一对比，按以下分类：
   - **持续**：两个时间段都出现，内容基本一致
   - **演变**：内容有显著变化（如关注点从 A 转向 B，但本质是同一个 Intent）
   - **消失**：在 06 月的日志中不再出现
   - **新涌现**：仅在 06 月出现
3. 分析演变原因——什么事件或认知触发了话题转移

**输出**：`outputs/intent-evolution.md`
- 演变分类结果
- 关键转折点分析（哪些事件或认知触发了转移）
- 固有张力识别（两个时间段都出现的冲突关系）
