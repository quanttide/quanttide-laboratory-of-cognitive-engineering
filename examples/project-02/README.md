# 项目二：思维演变长期分析

在一个月时间尺度（05-06 ~ 06-07）上追踪话题和意图的演变，识别持续存在的固有张力。

**核心问题**：
- 05-06~05-25 期间有哪些核心话题和意图？
- 与 06-01~06-07 的 13 个 Intent 相比，哪些持续、哪些消失、哪些新出现？
- 消失和出现之间是否有因果关系？

**方法概要**：先独立对 05-06~05-25 重新运行完整的 Notion→Topic→Intent 流程，再与 Project 1 的结果对比——避免参考偏差。

## 任务

### 2.1 独立话题分类

对 05-06~05-25 的 20 篇日志独立进行话题分类，不使用 Project 1 的 9 个话题作为参考。

**输入**：`../../assets/raw/2026-W19/` ~ `2026-W22/`（20 篇）

**方法**：
1. 逐日阅读每篇日志，以自然段落为单位提取话题片段
2. 以"意图"为边界区分话题
3. 跨日出现的相同话题合并归类
4. 暂难归类的内容归入"其他"待后续澄清

**输出**：`outputs/old-topics.md`
- 独立识别出的话题列表
- 每个话题涉及日期和关键段落引用

### 2.2 独立意图识别

基于 2.1 独立识别的话题，提炼核心 Intent。

**输入**：2.1 的输出

**方法**：
1. 对每个话题，通读所有关键段落，提炼核心 Intent
2. 以"为了……"或"想要……"句式表述
3. 标注清晰度分级

**输出**：`outputs/old-intents.md`
- 独立识别出的 Intent 列表
- 每个 Intent 的归属话题、表述、关键证据

### 2.3 意图演变对比

将 2.2 的独立结果与 Project 1 的 13 个 Intent 对比分析。

**输入**：`outputs/old-intents.md` + `../../assets/refined/intents.md`

**方法**：
1. 逐对对比，按以下分类：
   - **持续**：两个时间段都出现，内容基本一致
   - **演变**：内容有显著变化但本质是同一个 Intent
   - **消失**：在 06 月日志中不再出现
   - **新涌现**：仅在 06 月出现
2. 分析关键转折点——什么事件或认知触发了话题转移
3. 识别在两个时间段都出现的固有张力

**输出**：`outputs/intent-evolution.md`
- 演变分类对照表
- 关键转折点分析
- 固有张力识别
