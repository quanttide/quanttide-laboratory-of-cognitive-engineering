# 项目二：五周思维演变对比分析

5 周（W19~W23）的独立 Intent 数据已就绪，通过跨周对比追踪创始人思维的演变轨迹。

**核心问题**：
- 哪些 Intent 贯穿全部 5 周（固有关注）？哪些只出现在特定周（情境触发）？
- 从 W19 到 W23，关注的焦点发生了怎样的迁移？
- 固有张力的演变：组织的、认知的、商业的——哪些是长期存在的？

## 任务

### 2.1 跨周 Intent 对齐

将所有 5 周的 Intent 合并去重，建立跨周对照表。

**输入**：`../../assets/cleaned/2026-W{19,20,21,22,23}/intents.md`

**方法**：
1. 汇总 5 周全部 Intent（W19:8 + W20:6 + W21:8 + W22:5 + W23:13 ≈ 40 个）
2. 按语义相似度合并为跨周 Intent 簇——同一簇内在不同周的不同表述视为同一个核心 Intent
3. 为每个跨周簇命名，标注其出现周次

**输出**：`outputs/cross-week-intents.md`
- 跨周 Intent 簇列表（每个簇含名称、出现周次、各周表述对比）

### 2.2 固有关系分析

在时间维度上分析 Intent 之间关系的稳定性。

**输入**：2.1 的输出 + `../../assets/cleaned/2026-W{19,20,21,22,23}/intent-relations.md`

**方法**：
1. 识别在所有周中都出现的稳定关系对
2. 识别只在某几周出现的临时关系对
3. 区分固有张力（多周出现/贯穿始终）和偶发张力（单周出现）

**输出**：`outputs/stable-relations.md`
- 稳定关系对列表
- 固有张力分析
- 关系演变总览

### 2.3 焦点迁移分析

在时间维度上分析 Intent 之间关系的稳定性。

**输入**：2.1 的输出 + `../../assets/cleaned/2026-W{19,20,21,22,23}/intent-relations.md`

**方法**：
1. 识别在所有周中都出现的稳定关系对
2. 识别只在某几周出现的临时关系对
3. 区分固有张力（多周出现/贯穿始终）和偶发张力（单周出现）

**输出**：`outputs/stable-relations.md`
- 稳定关系对列表
- 固有张力分析
- 关系演变总览

### 2.4 冲突演化分析

追踪各周识别出的冲突关系，看哪些冲突是短期摩擦、哪些是长期结构性张力。

**输入**：`../../assets/cleaned/2026-W{19,20,21,22,23}/intent-relations.md`

**方法**：
1. 汇总 5 周的全部冲突关系（conflicts 类型）
2. 按冲突双方的性质分类：
   - **结构性冲突**：出现在 3 周以上，源自内在矛盾（如"快速试错 vs 深度建模"）
   - **情境性冲突**：出现在 1-2 周，由具体事件触发（如"商业压力 vs 认知消耗"）
3. 分析冲突的演化——同一个冲突在 W19→W23 之间是加剧了还是缓和了？有没有被解决？
4. 识别最高频的冲突模式——创始人在思考中反复面临的权衡是什么

**输出**：`outputs/conflict-evolution.md`
- 结构性冲突清单（贯穿多周的固有权衡）
- 情境性冲突清单（单次事件引发的短期摩擦）
- 冲突演化路径图
- 核心冲突模式总结

### 2.5 情境意识提炼

从 5 周的日志中提取创始人捕捉到的外部信号——他注意到了什么、在跟踪什么指标、什么事件触发了他的反应。

**输入**：`../../assets/raw/2026-W{19,20,21,22,23}/`（35 篇）+ 2.1~2.4 的各输出

**方法**：
1. 遍历所有日志，标记每个 Intent/Thought 触发的**外部情境信号**（市场变化、团队事件、客户反馈、技术趋势等）
2. 按领域分类：团队 / 商业 / 产品 / 技术 / 个人
3. 绘制各周的情境雷达——每周创始人的注意力分布在哪些外部信号上
4. 对比情境信号的演变——W19 关注的外部信号和 W23 关注的有何不同

**输出**：`outputs/situational-awareness.md`
- 领域信号目录（按领域分组的外部信号列表）
- 每周情境雷达（周度注意力分布图）
- 信号演变路径（哪些信号消失、哪些新出现）

### 2.6 心智模型提炼

从固有关系、冲突模式、Intent 簇中提取创始人用来解释情境的底层因果信念。

**输入**：2.2 固有关系 + 2.4 冲突演化 + 2.1 跨周 Intent 对齐

**方法**：
1. 从固有关系对中提取**因果信念**——如"人事优先 → 韧性高"、"标准化 → 可维护"
2. 从冲突模式中提取**权衡框架**——如"速度 vs 深度"、"人治 vs 法治"
3. 从跨周 Intent 簇中提取**认知框架**——如"反脆弱"、"意图工程"、"二阶控制论"
4. 划分哪些心智模型贯穿全部 5 周（稳定信念）、哪些只在某几周出现（情境信念）
5. 识别模型升级的关键节点——某个心智模型被替换或精化的时刻

**输出**：`outputs/mental-models.md`
- 心智模型清单（名称 + 表述 + 类型：因果信念/权衡框架/认知框架）
- 稳定模型 vs 情境模型对照表
- 心智模型升级路径（模型替换/精化的时间线）
