# 量潮认知工程实验室

认知工程的实验资产与示例项目仓库。

## 结构

```
data/
├── founder-fiction/     # 小说成稿示例（13篇，作为认知工程实验材料）
└── founder-journal/     # 日记条目示例（28篇，2026-05-06 ~ 2026-06-08）
examples/
└── README.md            # 当前实验说明与要求
```

## 用途

- **实验资产** — `data/` 下的材料可作为认知工程工具（如思考云 TUI）的输入素材
- **实验记录** — `examples/README.md` 记录了当前的实验目标、方法论和分级组织方式
